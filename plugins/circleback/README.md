# Circleback

Bring context from [Circleback](https://circleback.ai) into Cursor. Search and access meeting notes, transcripts, calendar events, emails, people, companies, and more.

## What's included

- **MCP server** — Connects to Circleback with OAuth
- **Rules** — Context on available tools so the AI knows how to use them

## Setup

Install the plugin from the Cursor Marketplace. On first use, you'll be prompted to authenticate with your Circleback account.
